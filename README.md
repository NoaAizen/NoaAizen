## Selected Projects

### [ValiSight](https://github.com/NoaAizen/ValiSight)

A team-developed multi-sensor perception and navigation system combining radar, IMU, thermal and visible camera data for real-time sensing, sensor fusion, multi-sensor tracking and navigation, running across OpenMV N6 and NVIDIA Jetson components.
My work focused on radar and IMU integration, radar calibration, sensor synchronization and timestamp handling, and pose initialization for the navigation flow.

### [Linux Shell in C++](https://github.com/NoaAizen/cpp-linux-shell)

A Unix-style shell built on Linux system calls: process creation with `fork()` and `execv()`, pipelines with `pipe()` and `dup2()`, input/output redirection, PATH lookup, background jobs and command history.

### [Real-Time Scheduling System](https://github.com/NoaAizen/real-time-scheduling-system)

EDF and RMS scheduling, periodic tasks with deadline handling, mutex synchronization, priority-inversion scenarios and priority inheritance, implemented on top of the SMARTS77 real-time framework in C++.

### [Drone Delivery Management System](https://github.com/NoaAizen/drone-delivery-management-wpf)

A C# / WPF application with a layered PL/BL/DAL architecture, XML persistence, battery and distance calculations, and a background drone delivery simulator.

### [Linux Netfilter Lab](https://github.com/NoaAizen/linux-netfilter-lab)

Linux kernel modules in C, progressing from a basic loadable module to Netfilter hooks for IPv4 packet inspection and a per-source-IP rate limiter using a kernel hash table and `jiffies`-based time windows. Developed with a partner.

### [Smart Medication Box](https://github.com/NoaAizen/smart-medication-box)

An Arduino prototype that detects objects inside a box with an HC-SR04 ultrasonic sensor and drives an LED and buzzer alert below a distance threshold.
